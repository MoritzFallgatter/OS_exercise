# OS_exercise

<!-- badges: start -->

<!-- badges: end -->

The goal of OS_exercise is to create an reproducible environment in
which we do something and present the results in an reproducible
environment. In this example, we investigate weather the probability
that a target region to be glaciated during the Last Glacial Maximum
(LGM) differs among climatic biomes using glm.

To reproduce the manuscript, please run the tar_make.R file.
